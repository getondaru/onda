# База хуков из Хитов Проекта

Рецепт собирает таблицу хуков — первых смысловых фраз, сказанных в ролике, —
из Транскриптов Instagram-Хитов одного Проекта Onda. Onda отдаёт Хиты и
Транскрипты; выбирает фразы и собирает таблицу агент пользователя. Не утверждай,
что Onda сгенерировала хуки, что хук объясняет успех Хита или что выборка
охватывает всю площадку.

Хук берётся только из Транскрипта. Подпись публикации не используй вообще: её
первая строка обычно не то, что звучит в начале ролика.

Рецепт работает сам по себе. Подробности API — в навыке `onda`, если он
установлен, и в `https://app.getonda.ru/openapi.json`.

## Обязательный контракт

- База `https://app.getonda.ru`, заголовок `X-API-Key` со значением из переменной
  окружения `ONDA_API_KEY`. Ключ отправляется только на этот адрес.
- Ключ берётся только из окружения или `.env`. Не проси вставить его в чат и
  никогда не печатай: ни в ответе, ни в логе, ни в команде (пиши
  `-H "X-API-Key: $ONDA_API_KEY"`). Нет переменной — попроси пользователя положить
  Ключ в `.env` или окружение и остановись. Ключ выпускается в Onda: Настройки →
  Для разработчиков → Выпустить ключ.
- Первый запрос — `GET /api/usage`. Не `200` — покажи код и тело и остановись.
- Тариф действует, если `is_root` или `unmetered` равно `true`, либо `plan` не
  `null`, `plan.started_at` задан и не позже текущего UTC, а `plan.expires_at`
  пуст или позже текущего UTC. Эти даты приходят в UTC без суффикса часового
  пояса; `units.limit = 0` может означать Ключ только для чтения и не закрывает
  Хиты. Если Тариф не действует — скажи это и остановись: не читай Хиты, не
  вызывай Транскрипт, не предлагай статьи, калькуляторы или другой бесплатный
  результат.
- `POST /api/transcribe` тратит минуты: только после явного согласия.
- Любой не-`2xx`: покажи фактический код и `detail` / `detail.message`, не
  объявляй успех. `402` с `detail.code` — нет действующего Тарифа; `429` —
  закончились минуты или сработал потолок, соблюдай `Retry-After`, если он есть.

## Что спросить у пользователя

1. Проект — имя или «Без проекта».
2. Объём (сколько Хитов) или период выборки. Если задан период — по какой дате:
   публикации (`created_at`), Найден (`found_at`) или Замера (`measured_at`).

Если не задано ни объёма, ни периода или не выбрана дата периода — уточни.

## Шаги

1. `GET /api/usage` — проверка подключения и Тарифа; запомни остаток минут
   (`transcription.minutes_limit` и `transcription.minutes_used`).
2. `GET /api/radar/folders` — найди `id` Проекта по имени. Для «Без проекта»
   используй `folder=none`. Не нашёл — покажи список имён и спроси.
3. `GET /api/radar/results?folder=<id|none>&scope=all&sort=recent&platform=instagram&limit=50&offset=0`
   — читай страницами по `offset`, пока не наберёшь объём или `offset` не дойдёт
   до `total`. Только Instagram: Транскрипт YouTube и других площадок этим путём
   недоступен; если пользователь ждал их, скажи об этом.
   - Бери только поля `item_id`, `username`, `url`, `created_at`, `found_at`,
     `measured_at`, `views`, `viral_ratio`. Поле `text` (подпись) не бери.
   - Период применяй только по выбранному полю даты. Строки без этого поля
     исключай и назови их число. Не останавливай листание по другому полю даты:
     порядок `sort=recent` — по дате публикации, а при её отсутствии по дате
     Скана, это не основание периода.
4. Покажи пользователю число выбранных Хитов и остаток минут и спроси согласие на
   Транскрипты. Уже готовый Транскрипт минут повторно не тратит. Без согласия
   таблицы нет — скажи это и остановись.
5. Раздели уникальные `item_id` на пакеты по 1–50; в каждом `limit` равен числу id
   в пакете:

   ```bash
   curl -sS -X POST https://app.getonda.ru/api/transcribe \
     -H "X-API-Key: $ONDA_API_KEY" -H "Content-Type: application/json" \
     -d '{"item_ids":["<id1>","<id2>","<id3>"],"platform":"instagram","limit":3}'
   ```

   Ответ `202` с `job_id`. Опрашивай `GET /api/transcribe/jobs/{job_id}`, пока
   `status` не `done` или `failed`. Текст бери из
   `result.items[].transcript_original` только у статусов `ok` и `skipped`.
   `empty`, `failed`, `not_found` — перечисли, текст не придумывай.
6. Из каждого полученного Транскрипта выпиши первую смысловую фразу дословно.
   Нет текста — нет строки.

## Результат

Markdown-таблица ровно с такими колонками:

| № | Хук (точная цитата) | Автор | Хит | Виральность | Дата Замера |
|---|---|---|---|---|---|
| 1 | «…» | @username | [ссылка](url) | 12,4 | 2026-10-01 |

- «Хук» — дословно из `transcript_original`; «Хит» — ссылка на `url`;
  «Автор» — `username`; «Виральность» — `viral_ratio`; «Дата Замера» —
  `measured_at`.
- Неизвестное поле оставь пустым, ноль не подставляй.
- Под таблицей: сколько Хитов прочитано, сколько исключено по дате периода, какие
  Транскрипты вернулись без текста или с ошибкой. Числа — на дату Замера, не на
  сегодня.
