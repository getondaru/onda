# Onda

Onda сохраняет публикации аккаунтов, за которыми следит пользователь в Instagram,
YouTube и TikTok, вместе с их показателями. Публикации, прошедшие Порог
виральности, называются Хитами. Аккаунт под наблюдением — Цель, группа Целей —
Проект. Разовый сбор публикаций одного аккаунта — Прогон, текст речи из ролика —
Транскрипт.

Onda отдаёт данные. Она не пишет тексты, не ищет по всей площадке и не объясняет,
почему публикация набрала просмотры. Таблицы, выводы и сценарии из этих данных
делаешь ты, агент пользователя, и так об этом и говоришь.

## Подключение

- База: `https://app.getonda.ru`. Других адресов у API нет.
- Авторизация: заголовок `X-API-Key` со значением из переменной окружения
  `ONDA_API_KEY`. Ключ отправляется только на `https://app.getonda.ru`.
- Точные схемы запросов и ответов: `https://app.getonda.ru/openapi.json`,
  человекочитаемо — `https://app.getonda.ru/docs`. Если поле есть в схеме, а здесь
  его нет, доверяй схеме.

Правила для Ключа:

- Ключ берётся только из `ONDA_API_KEY` (окружение или `.env`). Не проси вставить
  его в чат. Если переменной нет — попроси пользователя положить Ключ в `.env` или
  в окружение и остановись.
- Никогда не печатай Ключ: ни в ответе, ни в логе, ни в показанной команде.
  В примерах команд пиши `-H "X-API-Key: $ONDA_API_KEY"`, не подставляя значение.

### Где взять Ключ

1. Войти в Onda на `https://app.getonda.ru`.
2. Меню аватара → **Настройки** → **Для разработчиков** → **Выпустить ключ**.
3. Сохранить секрет в `ONDA_API_KEY`: он показывается один раз, повторно прочитать
   его нельзя.

Выпустить или перевыпустить Ключ можно только при действующем оплаченном Тарифе;
посмотреть и отозвать прежние Ключи можно всегда, в том же блоке. Сам агент Ключ
не выпускает: управление Ключами работает только из браузера пользователя.

## Первый запрос: проверка подключения и Тарифа

Всегда начинай с `GET /api/usage`:

```bash
curl -sS https://app.getonda.ru/api/usage -H "X-API-Key: $ONDA_API_KEY"
```

- Не `200` — сообщи пользователю фактический код и тело ответа и остановись.
  Не сообщай об успехе. `401` — Ключ неизвестен или отозван.
- `200` — покажи Тариф, остаток Единиц Прогона (`units`) и минут распознавания
  (`transcription`) из ответа. Числа лимитов бери только из этого ответа.

Тариф действует, если `is_root` или `unmetered` равно `true`, либо одновременно:
`plan` не `null`, `plan.started_at` задан и не позже текущего UTC,
`plan.expires_at` пуст или позже текущего UTC. Эти даты приходят в UTC без
суффикса часового пояса. `units.limit = 0` сам по себе не означает, что Тариф
истёк: Ключ может быть намеренно ограничен чтением; с таким Ключом читай Хиты,
но не запускай Прогон.

Если Тариф не действует — скажи пользователю это и что Тариф можно оформить в
Onda, и на этом остановись: не читай Хиты, не запускай Прогон и Транскрипт, не
предлагай взамен статьи, калькуляторы или другой бесплатный результат.

## Чтение (по умолчанию)

Без явной просьбы пользователя навык только читает. Числа в ответах относятся к
дате Замера (`measured_at`), а не к текущему моменту: не называй их актуальными.

1. `GET /api/usage` — Тариф и остатки (см. выше).
2. `GET /api/radar/folders` — Проекты: `folders[].id`, `folders[].name`.
3. `GET /api/radar/targets` — Цели пользователя; `folder=<id>` — один Проект,
   `folder=none` — Цели без Проекта.
4. `GET /api/radar/results?scope=all&sort=recent&limit=50&offset=0` — лента Хитов.
   `folder=<id>|none` — один Проект, `q=<текст>` — поиск по подписи,
   `limit` не больше 200, листай по `offset`, пока `offset < total`.
   `platform=instagram|youtube|tiktok|twitter` добавляй только если этого требует
   задача пользователя; без него приходят Хиты всех площадок.
   `GET /api/radar/results.csv?folder=<id>&days=30` — те же Хиты одним CSV.
5. `GET /api/radar/targets/{id}/hits?period=30` (`7|30|90|all`) и
   `GET /api/radar/targets/{id}/summary?days=30` (`7|30|90`) — Хиты и сводка одной
   Цели. Вызывай только для `target_id` из ответа Onda; если у Хита
   `target_id = null`, эти маршруты по нему не вызывай.

Основные поля Хита: `item_id`, `platform`, `username`, `url`, `text` (подпись),
`created_at` (публикация), `found_at` (Найден), `measured_at` (дата Замера),
`views`, `likes`, `comments_count`, `followers_at_scan`, `viral_ratio`
(Виральность — просмотры к подписчикам). Пустое поле оставляй пустым, не
подставляй ноль.

Без действующего Тарифа `GET` не отвечает `402`, но лента обрезана: в ней нет
Хитов, найденных после окончания Тарифа. Поэтому навык и останавливается после
`/api/usage` (см. выше).

## Расходующие операции (только по явной просьбе)

Эти вызовы тратят пределы Тарифа. Перед каждым назови пользователю, что будет
вызвано и сколько примерно это стоит по `units.scale` или остатку минут из
`/api/usage`, и дождись явного согласия. Создавать, менять и удалять Цели, Проекты
и Пометки навык не умеет.

### Прогон Instagram или YouTube

```bash
curl -sS -X POST https://app.getonda.ru/api/parse/instagram \
  -H "X-API-Key: $ONDA_API_KEY" -H "Content-Type: application/json" \
  -d '{"identifier":"username","period_days":30,"max_items":50}'
```

- `POST /api/parse/instagram` — `identifier` (имя аккаунта или ссылка), окно
  `period_days` либо `date_from`/`date_to`, `max_items` до 500,
  `content_types` — `["posts"]`, `["reels"]` или оба.
- `POST /api/parse/youtube` — `identifier` (канал), `mode: "channel"` или
  `mode: "search"` (поисковый запрос), то же окно, `video_type`
  `all|shorts|long`.
- Успешный Прогон возвращает `200` и фактический результат; покажи его, не
  подменяя выводом об успехе.
- Цена в Единицах Прогона: канальный Прогон стоит по наименьшему из
  `units.scale.days_7|days_30|days_365`, покрывающему окно; без окна — как за
  `days_365`. Прогон Instagram одного типа контента стоит по соответствующему
  `units.scale.single_stream.days_7|days_30|days_365` с тем же выбором окна.
  `mode: "search"` стоит `units.scale.search_page` за одну страницу.

### Транскрипт Instagram-публикации

```bash
curl -sS -X POST https://app.getonda.ru/api/transcribe \
  -H "X-API-Key: $ONDA_API_KEY" -H "Content-Type: application/json" \
  -d '{"item_ids":["<id1>","<id2>"],"platform":"instagram","limit":2}'
```

- `POST /api/transcribe` тратит минуты распознавания. Тело:
  `{"item_ids":[…],"platform":"instagram","limit":N}`.
- В пакете от 1 до 50 уникальных Instagram-`item_id`; `N` равен числу уникальных
  id именно в этом пакете (37 id — `"limit":37`). Больше id, чем `limit`, не
  передавай: это `422`. Больше 50 id — несколько пакетов.
- `platform` передавай всегда: без него совпавший `item_id` на разных площадках
  получает `422 transcribe_platform_ambiguous`.
- Подходят `item_id` Хитов пользователя и публикаций из его Прогонов.
- Ответ `202` с `job_id`. Опрашивай `GET /api/transcribe/jobs/{job_id}`, пока
  `status` не станет `done` или `failed`. Текст — `result.items[].transcript_original`
  у элементов со статусом `ok` или `skipped`; `empty`, `failed`, `not_found` —
  сообщи как есть, текст не придумывай.
- Для YouTube этот маршрут Транскрипта не даёт: YouTube-id в него не передавай и
  прямо скажи пользователю, что Транскрипт YouTube через навык недоступен.

## Ошибки: передавай как есть

Никогда не выдумывай успех. При любом не-`2xx` покажи пользователю код и
`detail` (или `detail.message`) из тела.

- `402` с `detail.code` = `plan_missing`, `plan_not_started` или `plan_expired` —
  нет действующего Тарифа; текст — `detail.message`.
- `402` без `detail.code` — отказ поставщика данных; Единицы за него вернутся.
  Сообщи `detail.message` и не советуй оплату.
- `429` — закончились Единицы, минуты или сработал общий потолок; текст из
  `detail`. Если пришёл заголовок `Retry-After`, не повторяй запрос раньше.
- Любой другой код Прогона (например, `403`/`404` YouTube по ключу или каналу,
  временный `503`) — передай код и `detail.message`, не объявляя успех и не
  советуя оплату.
