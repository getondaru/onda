# Сценарий по Транскрипту Хита

Рецепт берёт один Instagram-Хит из Проекта Onda, получает его Транскрипт и пишет
по нему новый сценарий для ниши пользователя. Onda отдаёт Хит и Транскрипт;
сценарий пишет агент пользователя. Не выдавай текст за работу Onda, не обещай
повторить Виральность, не объясняй причину успеха Хита и не копируй Транскрипт
целиком вместо нового сценария.

Рецепт работает сам по себе. Подробности API — в навыке `onda`, если он
установлен, и в `https://app.getonda.ru/openapi.json`.

## Обязательный контракт

- База `https://app.getonda.ru`, заголовок `X-API-Key` со значением из переменной
  окружения `ONDA_API_KEY`. Ключ отправляется только на этот адрес.
- Ключ берётся только из окружения или `.env`. Не проси вставить его в чат и
  никогда не печатай: ни в ответе, ни в логе, ни в команде (пиши
  `-H "X-API-Key: $ONDA_API_KEY"`). Нет переменной — попроси пользователя положить
  Ключ в `.env` или окружение и остановись. Ключ выпускается в Onda: Настройки →
  Для разработчиков → Выпустить ключ.
- Первый запрос — `GET /api/usage`. Не `200` — покажи код и тело и остановись.
- Тариф действует, если `is_root` или `unmetered` равно `true`, либо `plan` не
  `null`, `plan.started_at` задан и не позже текущего UTC, а `plan.expires_at`
  пуст или позже текущего UTC. Эти даты приходят в UTC без суффикса часового
  пояса; `units.limit = 0` может означать Ключ только для чтения и не закрывает
  Хиты. Если Тариф не действует — скажи это и остановись: не читай Хиты, не
  вызывай Транскрипт, не предлагай статьи, калькуляторы или другой бесплатный
  результат.
- `POST /api/transcribe` тратит минуты: только после явного согласия.
- Любой не-`2xx`: покажи фактический код и `detail` / `detail.message`, не
  объявляй успех. `402` с `detail.code` — нет действующего Тарифа; `429` —
  закончились минуты или сработал потолок, соблюдай `Retry-After`, если он есть.

## Что спросить у пользователя

- Хит: Проект (имя или «Без проекта») и ссылка на публикацию или её `item_id`.
- Ниша пользователя.
- Если важно: площадка назначения, длительность, тон, призыв к действию.

Незаполненные творческие ограничения уточни или пометь в ответе как «не задано».
Не приписывай их Onda.

## Шаги

1. `GET /api/usage` — проверка подключения, Тарифа и остатка минут.
2. `GET /api/radar/folders` — `id` Проекта по имени; для «Без проекта» —
   `folder=none`.
3. `GET /api/radar/results?folder=<id|none>&scope=all&limit=50&offset=0` —
   листай по `offset` до `total`, пока не найдёшь Хит по `item_id` или `url`.
   Не нашёл — скажи об этом и остановись.
4. Хит должен быть Instagram (`platform = "instagram"`): Транскрипт YouTube и
   других площадок этим путём недоступен — скажи это и остановись.
5. Покажи пользователю ссылку (`url`) и автора (`username`) Хита и попроси
   подтвердить выбор и расход минут на Транскрипт.
6. После согласия:

   ```bash
   curl -sS -X POST https://app.getonda.ru/api/transcribe \
     -H "X-API-Key: $ONDA_API_KEY" -H "Content-Type: application/json" \
     -d '{"item_ids":["<item_id>"],"platform":"instagram","limit":1}'
   ```

   Ответ `202` с `job_id`. Опрашивай `GET /api/transcribe/jobs/{job_id}`, пока
   `status` не `done` или `failed`.
7. Пиши сценарий только из непустого `result.items[0].transcript_original` со
   статусом `ok` или `skipped`. Статус `empty`, `failed` или `not_found` — сообщи
   его как есть и не пиши текст «по Транскрипту».

## Результат

```markdown
# Черновик сценария
Источник: <ссылка на Хит>
Ниша: <ввод пользователя>

## Хук
...

## Основная часть
| Блок | Текст | Визуал / текст на экране |
|---|---|---|
| ... | ... | ... |

## CTA
...

## Что взято из источника
- <короткие опорные тезисы из Транскрипта>
```

- Сценарий новый: структура и приёмы источника, слова и примеры — под нишу
  пользователя.
- В «Что взято из источника» — короткие тезисы своими словами, не полный текст
  Транскрипта.
- Не заданные пользователем ограничения (длительность, тон, CTA) помечай как
  «не задано».
